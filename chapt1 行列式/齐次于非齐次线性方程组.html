齐次 vs 非齐次线性方程组

面向大一新生：从几何直觉看懂两类方程组的定义、解的结构与工程意义（无源 = 齐次 · 有源/受迫 = 非齐次）

齐次 Ax=0（无源/自由响应） 非齐次 Ax=b（有源/受迫响应） 关键点 / 交点

① 定义对比：有没有"源"（外部激励）

齐次线性方程组 Ax = 0

A 是系数矩阵，x 是未知向量，右端恒为 0。
例（2 元）： 2x + y = 0
x − y = 0

✅ 必有零解 x=0（无源时系统可"静止"）。解的集合对加法、数乘封闭 → 构成向量空间（解空间）。

非齐次线性方程组 Ax = b

右端 b ≠ 0（至少一个分量非零），代表外部激励/载荷。
例： 2x + y = 3
x − y = 0

❌ 不一定有零解；解集 = 一个特解 xₚ + 齐次通解 xₕ，是解空间平移后的一族，一般不构成向量空间。

3D 演示：b 改变 → 平面平移（是否过原点）

平面族 2x + y − z = b。b=0 时过原点（齐次）；b≠0 时不过原点（非齐次）。拖动滑块改变 b。

b=0：平面过原点（齐次 Ax=0）。

② 几何意义：解 = 直线 / 平面的交点

2D 两直线交点（齐次 vs 非齐次对照）

齐次（过原点）：
L₁: x + y = 0　　L₂: x − y = 0
交点 = (0,0) 原点（无源时唯一"静止"交点）
非齐次（平移后）：
L₁: x + y = 2　　L₂: x − y = 0
交点 = (1,1)（有源时交点离开原点）
2D·齐次(蓝) vs 非齐次(红)

👉 两族直线画在同一坐标系：蓝色为齐次方程组（两线交于原点），红色为非齐次方程组（两线交于 (1,1)）。一目了然——齐次交点是原点，非齐次交点因"源"而偏移。

3D：两组平面的交线（大画布，可拖拽旋转/滚轮缩放）

齐次组 x+y−z=0 与 x−y=0 的交线（过原点）；非齐次组平移后 x+y−z=2 与 x−y=0 的交线。

几何·两组交线（大画布）

蓝色交线过原点；红色交线由非齐次方程给出，整体平移。

③ 解的结构：非齐次通解 = 齐次通解 + 一个特解

具体方程组（3 元示例）：
齐次　x + y − z = 0　（解直线 x=t, y=t, z=2t）
非齐次　x + y − z = 2　（解直线 = 特解 (1,0,−1) + t(1,1,2)）

3D：拖动 t，看齐次解直线 + 非齐次解直线

0.00

蓝点=齐次解 xₕ(t)；红点=非齐次解 xₚ+xₕ(t)。

t 的调节意义是什么？

齐次方程 x+y−z=0 的解是一条过原点的直线，方向向量为 (1,1,2)。参数 t 表示"沿这条解直线走了多远"：

xₕ(t) = (t, t, 2t)　（t 任意实数）

非齐次方程的通解 = 一个特解 xₚ 加上齐次通解：

x(t) = xₚ + xₕ(t) = (1,0,−1) + (t, t, 2t)

👉 拖动滑块改变 t，相当于在解直线上连续取不同的解点。t 每取一个值，就得到一个满足方程的具体解；蓝点遍历齐次解直线，红点遍历非齐次解直线（整体由特解平移得到）。

记忆口诀：齐次给"方向/形状"（解空间），特解给"位置"（因源而平移）。两者相加 = 非齐次全部解。

④ 工程意义：无源（齐次） vs 有源（非齐次）

工程上最本质的区别：齐次描述"无源/自由响应"（无外部激励，系统按自身特性演化）；非齐次描述"有源/受迫响应"（存在外部载荷、电源、边界驱动等"源"）。

👉 规律：把"源/载荷/电源/边界"全部置零 → 齐次（无源）；保留它们 → 非齐次（有源）。齐次刻画系统自身特性（模态、稳定性），非齐次刻画系统在源驱动下的实际响应。

弹簧-质量系统 Ku = f（有限元原型）

K = [[2,−1,0],[−1,2,−1],[0,−1,2]],　u = 竖直位移,　f = 竖直外力

弹簧刚度均为 k=1。三质量块由四根弹簧竖直串联于上下两固定墙之间（下墙—⚙—m₁—⚙—m₂—⚙—m₃—⚙—上墙），蓝色方块为质量块，灰弹簧两端明确锚在块面/墙面上。
f=(0,b,0)（仅中间受竖直外力 b，方向与弹簧/位移同轴）→ 竖直位移解 u=(b/2, b, b/2)：中间块位移最大，两端为一半，拖动 b 可看到三块随弹簧伸缩同步升降，红箭头示外力方向。
已验证 K·[b/2,b,b/2]ᵀ = [0,b,0]ᵀ 对任意 b 成立 ✓（外力方向=位移方向=弹簧轴方向，符合实际受力）

关于"齐次无源场景的稳定性分析"

澄清：齐次系统的稳定性，指的是系统"自身的自由运动"是否衰减回平衡（如阻尼振动最终停下），它刻画的是系统内部特性（质量/刚度/阻尼），而不是"有没有外部输入"。

✅ 正确表述：稳定性与外部输入无关——无论外加激励多复杂，只要系统本身的齐次（零输入）响应是稳定的，受迫响应就"可控"。换句话说：

  • 齐次（无源）研究的是"系统自己稳不稳"：给一个初始扰动后，系统能否自行回到平衡（如 u(t)→0）。这是稳定性的定义。
  • 非齐次（有源）研究的是"在外部源驱动下，系统如何响应"：稳态解由源 b 决定，而暂态是否发散仍由齐次部分的稳定性决定。
  • 因此工程上先分析齐次（无源）的稳定性，再叠加非齐次（有源）的特解——这与"非齐次通解 = 齐次通解 + 特解"在结构上完全对应。
一句话总结：齐次 = 系统"关掉所有源"后的自由行为（据此判断稳不稳）；非齐次 = 打开源后系统被驱动的行为。稳定性是系统内禀属性，确实与外部输入无关。
