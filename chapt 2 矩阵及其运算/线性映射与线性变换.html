线性映射 与 线性变换

二者都是"保持加法和数乘"的线性规则；区别仅在于：输入空间与输出空间是否为同一个空间。

一、标准定义

1. 线性映射（Linear Mapping）
设 V、W 是同一数域上的向量空间。若映射 T: V -> W 满足对任意 u, v 属于 V、任意标量 c，都有：
T(u + v) = T(u) + T(v)，   T(c u) = c T(u)
则称 T 为从 V 到 W 的线性映射。
要点：V 与 W 可以是不同的空间（维数也可不同）。矩阵表示 A 是 m x n 矩阵（m 与 n 未必相等）。
2. 线性变换（Linear Transformation）
当线性映射 T: V -> W 中 W = V（即输出空间就是输入空间自身）时，称 T 为 V 上的线性变换。
T: V -> V，  同样满足 T(u+v)=T(u)+T(v)，T(c u)=c T(u)
要点：输入与输出在同一个空间里。矩阵表示 A 必为方阵（n x n）。

二、二者对比

线性映射 T: V -> W

  • V、W 可为不同空间
  • 矩阵 A：m x n（可非方阵）
  • 例：加速度计把 3D 运动（R^3）映射为 1 路电压（R）
  • 可"降维/换空间"

线性变换 T: V -> V

  • V = W，同一空间
  • 矩阵 A：n x n（必为方阵）
  • 例：平面旋转把 R^2 上的点仍送回 R^2
  • 是"空间内部的运动"
关系：线性变换是线性映射的特例（W = V）。二者都要求"线性"——即先相加再映射，等于分别映射后再相加。

四、工程意义：为什么工程师离不开这两个概念

线性映射和线性变换的本质，是把"物理世界"翻译成"可计算数学模型"的工具。
只要一个系统满足叠加性（多个输入的总响应 = 各自响应之和）和齐次性（输入放大 k 倍，输出也放大 k 倍），它就能写成一个矩阵；而矩阵的作用，正是一个线性映射 / 线性变换。

线性映射的工程意义

  • 传感器建模：加速度计把三维运动（R^3）映射为一维电信号（R），不同物理量空间之间的转换。
  • 电路分析：导纳矩阵 Y 把节点电压向量映射为支路电流向量，是"电压空间 → 电流空间"的线性映射。
  • 有限元 / 结构分析：刚度矩阵 K 把节点位移（几何空间）映射为节点力（力学空间），F = K x。
  • 控制工程：输出矩阵 C 把状态向量 x（内部状态空间）映射为可测输出 y（传感器输出空间），y = C x。
一句话：凡是"一类物理量 → 另一类物理量"的线性转换，都是线性映射。

线性变换的工程意义

  • 坐标变换：机器人把世界坐标系下的位置，旋转到自身机体坐标系下（仍是 R^3 → R^3），用于导航与控制。
  • 参考系旋转：电机矢量控制（FOC）中，把定子三相静止坐标系下的电流，变换到随转子旋转的 dq 坐标系（Park 变换）。
  • 结构动力学：模态分析用正交变换把耦合的质量/刚度矩阵对角化，把"物理坐标"变换为"模态坐标"。
  • 图像处理：对图像做旋转、缩放、剪切，本质是在同一像素平面（R^2）上做线性变换。
一句话：凡是"同一空间内部重新摆放 / 重新选基"的线性操作，都是线性变换。
如何帮学生快速区分（教学提示）
① 先看单位 / 物理量：输入是"位移"、输出是"力"→ 不同空间 → 线性映射（如 F=Kx）。
② 再看坐标 / 参考系：输入、输出都是"位置"，只是方向或基变了 → 同一空间 → 线性变换（如旋转矩阵）。
③ 判断矩阵形状：非方阵（m≠n）一定是映射；方阵（n×n）多为变换（也可视为映射到自身的特殊映射）。
④ 牢记共同内核：二者都满足 T(u+v)=T(u)+T(v)、T(cu)=cT(u)——这正是工程师能"分工况、分模态、分参考系"分别计算再叠加的数学依据（叠加原理）。
总结：线性映射是"跨空间"的线性规则，线性变换是"同空间"的线性规则；后者是前者的特例。工程建模时，先判断"空间是否改变"，再决定用映射还是变换，就能把复杂物理系统写成简洁的矩阵算式。
