线性相关 vs 线性无关 — 工程实例

Interactive Animation Demo

【场景一】线性无关
桥梁三向支撑力

✓ 线性无关

• 三个力方向各不相同

• 没有一个力能被其他力组合表示

• 方程组有唯一解 → 结构稳定

【场景二】线性相关
桥梁冗余支撑

✗ 线性相关

• 三个力都在同一方向

• F₃ = a·F₁ + b·F₂ (可被表示)

• 方程组无穷解 → 结构不稳定

数学定义

线性无关：

若 c₁v₁ + c₂v₂ + ... + cₙvₙ = 0
则必有 c₁ = c₂ = ... = cₙ = 0

⇒ 只有零解，向量组线性无关

线性相关：

存在不全为零的 cᵢ
使得 c₁v₁ + c₂v₂ + ... + cₙvₙ = 0

⇒ 存在非零解，向量组线性相关
★ 工程意义： 线性无关 = 每个约束提供独立信息 | 线性相关 = 存在冗余约束，可能导致结构不稳定或计算困难
