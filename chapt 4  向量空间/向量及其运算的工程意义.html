先分清三种"向量"（依据：同济《线性代数》五版 §4.1 + 向量分析通用约定）

名称身份有没有空间方向例子
物理向量有大小+方向的物理量（客观存在）✅ 有力 F、速度 v、电场 E、磁场 B、流速、热流密度 q
几何向量物理向量的可视化：带方向的线段（有向线段）✅ 有（可画箭头）在纸上画 F 的箭头、桁架杆力箭头
代数向量几何向量的代数形式：一组有序数 (a₁,…,aₙ)ᵀ❌ 无（只是数列/状态数组）节点电压列向量 v=(v₁,…,vₙ)ᵀ、状态 x=(p,T,ω)ᵀ
同济口径补充：n 个有序数组成的数组称为 n 维向量；写成一行是行向量、写成一列是列向量，都按矩阵运算法则运算（同济五版 §4.1）。

容易踩坑的三类量（不能当"几何箭头"）

量有没有方向正确归类说明
节点电压 vₖ、支路电压、电动势❌ 仅参考极性（±）代数向量（列向量，解 Ax=b 用）不能画成空间箭头；nodal 方程 Y·v=i
三相相量 U=(U_A,U_B,U_C)ᵀ、电流相量 I❌（复数二维表示）相量 / 复数（非几何向量）相量≠正弦量；仅表示大小+初相
功率 P、Q、复功率 S=P+jQ❌标量 / 复标量不画箭头、不参与叉积；P=Re(U·I*)
三分法的来源："physical vector（物理量/有向线段）→ geometric vector（几何箭头表示）→ algebraic vector（有序数组）"是向量分析中的通用约定（见 PlanetMath "vector" 词条）；"n 个有序数组成的数组称为 n 维向量"即同济《线性代数》五版 §4.1 的代数向量定义。两者合在一起，就是本页"先分层、再讲工程意义"的口径。
一句话防踩坑：能在空间里画带方向箭头、能做点积/叉积的，只有物理向量→几何向量（力、E、B、流速 v、热流 q）。节点电压/相量/功率都不是几何箭头。

几何向量的运算（仅限物理向量：力/场/速度）

α（如力 F₁） β（如力 F₂） α+β = 合力（平行四边形对角线） α 在 β 上的投影

叉积 α×β（三维 · 右手定则）

橙色箭头 = α×β，方向由右手定则给出，模 = ‖α‖‖β‖sinθ = 两向量张成的平行四边形面积。
工程意义：α×β 在电机/透平里就是转矩/力矩。磁场对载流导体力 F=I·l×B（电动机推力）；主轴力矩 M=r×F（叶轮气动力对轴）；角动量 L=r×mv。

核心桥接：矩阵 × 向量 = 列向量的线性组合

若 A=[c₁ c₂ … cₙ]（cⱼ 为 A 的第 j 列），x=(x₁,…,xₙ)ᵀ，则
A·x = x₁c₁ + x₂c₂ + … + xₙcₙ
即：矩阵乘向量 = 以 x 各分量为系数，对 A 的各列做线性组合。A 的列向量是一组"方向/基构件"，x 是"配方/导航指令"。
与方程组等价：线性方程组 Ax=b ⇔ "b 能否由 A 的列向量线性组合表示"。有解 ⇔ b 在 A 的列空间内；唯一解 ⇔ A 列满秩。

交互：用两组基向量合成目标 b

基向量 v₁=(2,1)ᵀ，v₂=(1,3)ᵀ。拖动目标 b=(b₁,b₂)，求系数 c₁、c₂ 使 c₁v₁+c₂v₂=b，即 A·c=b，A=[v₁ v₂]。

工程意义：nodal/潮流方程 Y·v=i、状态空间 x'=A·x+B·u、三相旋转磁动势合成、桁架轴力分解，本质都是 Ax=b / A·x=b——把物理状态/力拆成基向量（基函数、模态、杆方向）的线性组合来求解。

给大一的底层的直觉：向量不是数组，是"带方向的物理量(几何箭头)"或"一组状态数(代数列向量)"； 加法=守恒/叠加，数乘=比例/线性齐次，点积=投影/传能，叉积=转矩/转轴，线性组合=解方程/模态分解=矩阵乘向量。
再次提醒：节点电压 v、相量 U/I、功率 P/Q/S 没有空间方向，不画几何箭头；把它们排成列向量 v、U 是为了解 Ax=b，它们是代数向量/复数，不是几何向量。
