矩阵秩的八条性质

依据同济《工程数学·线性代数》§3.2 · 不用证明，先看懂画面 · 大一刚入校友好版

★教材怎么定义“秩”？

对矩阵 A，在它所有子式中，阶数最高且不等于零的那个子式的阶数，就叫 R(A)。

两个等价说法（§3.2 定理）：

  • 初等行变换化成阶梯形后，非零行的行数 = R(A)。
  • R(A) = R(Aᵀ)，行和列的最高非零子式阶数一样。
💡 直观：秩 = 矩阵里“真正有内容的行/列条数”，废话行（全零或重复）不计入。

1八条性质 · 画面化解读

①
0 ≤ R(A) ≤ min(m, n)

🎲 类比：最多只能从 m 行、n 列里凑出一个非零子式，阶数不可能超过行数或列数。

②
R(Aᵀ) = R(A)

🪞 类比：转置只是把矩阵翻过来，子式是否为零不变，所以行秩 = 列秩。

③
A ∼ B（初等变换）⇒ R(A)=R(B)

📷 类比：初等行变换只是“换角度整理”，不会凭空造出或消灭非零子式，阶梯形行数不变。

④
P、Q 可逆 ⇒ R(PAQ)=R(A)

🕶️ 类比：可逆矩阵 = 若干次初等变换，本质还是整理，不改变秩。

⑤
R(A) ≤ R(A,b) ≤ R(A)+1

🧩 类比：往矩阵右边加一列 b，要么 b 能被原有列组合出来（秩不变），要么带来一个新方向（秩+1）。绝不会+2，因为只加了一列。

（这是判断方程组解的存在性的基础，第5章会细讲）

⑥
R(A±B) ≤ R(A)+R(B)

🤝 类比：两矩阵相加，新矩阵的行可能互相抵消，独立行数不会超过两边独立行数之和。

⑦
R(AB) ≤ min{R(A), R(B)}

🚰 类比：相乘相当于把 B 的列再组合一次，组合不出比 B 本身更多的独立列；又被 A 的行再过滤一次，也超不过 A 的行数。

3 2

⇒ R(AB) 最多是 2 = min{R(A),R(B)}

⑧
AB = O ⇒ R(A)+R(B) ≤ n

🕳️ 类比：B 扔出的列，全被 A 变成零。A 能“吞掉”的列数，加上 B 本身独立列数，不能超过总维数 n。

这是教材 §3.2 给出的性质⑧，也叫 Sylvester 不等式的推论。
