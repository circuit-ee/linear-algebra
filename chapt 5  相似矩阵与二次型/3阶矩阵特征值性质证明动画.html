3阶矩阵特征值性质证明

特征值之和等于矩阵的迹 · 特征值之积等于矩阵的行列式

预备知识

设3阶矩阵 A 为：

[
a₁₁
a₁₂
a₁₃
]
[
a₂₁
a₂₂
a₂₃
]
[
a₃₁
a₃₂
a₃₃
]

矩阵 A 的特征值为 λ₁, λ₂, λ₃，特征多项式定义为：

f(λ) = det(λI - A)

根据特征多项式理论，3阶矩阵的特征多项式可表示为：

f(λ) = λ³ - (a₁₁+a₂₂+a₃₃)λ² + (a₁₁a₂₂+a₁₁a₃₃+a₂₂a₃₃-a₁₂a₂₁-a₁₃a₃₁-a₂₃a₃₂)λ - det(A)

性质一证明：特征值之和等于矩阵的迹

步骤1：特征多项式与特征值关系

特征多项式 f(λ) = det(λI - A) 的根就是矩阵 A 的特征值 λ₁, λ₂, λ₃。

根据多项式根与系数的关系（韦达定理），对于三次方程：

λ³ + c₁λ² + c₂λ + c₃ = 0

三个根满足：

λ₁ + λ₂ + λ₃ = -c₁

步骤2：对比特征多项式系数

矩阵 A 的特征多项式为：

f(λ) = λ³ - (a₁₁+a₂₂+a₃₃)λ² + ... - det(A)

与标准三次方程对比，系数 c₁ = -(a₁₁+a₂₂+a₃₃)

根据韦达定理：

λ₁ + λ₂ + λ₃ = -c₁ = a₁₁ + a₂₂ + a₃₃

而 a₁₁ + a₂₂ + a₃₃ 正是矩阵 A 的迹 tr(A)

步骤3：得出结论

λ₁ + λ₂ + λ₃ = tr(A) = a₁₁ + a₂₂ + a₃₃

✅ 特征值之和等于矩阵的迹，证明完成！

性质二证明：特征值之积等于矩阵的行列式

步骤1：特征多项式常数项分析

特征多项式 f(λ) = det(λI - A) 的常数项为 f(0)

f(0) = det(0·I - A) = det(-A) = (-1)³ det(A) = -det(A)

所以特征多项式的常数项为 -det(A)

步骤2：利用韦达定理

特征多项式 f(λ) = λ³ + c₁λ² + c₂λ + c₃ 的常数项为 c₃

从步骤1可知 c₃ = -det(A)

根据韦达定理，三个根的乘积为：

λ₁ · λ₂ · λ₃ = -c₃

步骤3：代入常数项表达式

将 c₃ = -det(A) 代入韦达定理公式：

λ₁ · λ₂ · λ₃ = -(-det(A)) = det(A)

步骤4：得出结论

λ₁ · λ₂ · λ₃ = det(A)

✅ 特征值之积等于矩阵的行列式，证明完成！

实例验证

考虑具体矩阵验证上述性质：

[
4
1
0
]
[
0
2
1
]
[
0
0
3
]

计算验证

矩阵的迹 tr(A) = 4 + 2 + 3 = 9

矩阵的行列式 det(A) = 4×2×3 = 24（上三角矩阵）

特征值：λ₁=4, λ₂=2, λ₃=3（上三角矩阵的特征值就是对角线元素）

特征值之和：4+2+3 = 9 = tr(A) ✅

特征值之积：4×2×3 = 24 = det(A) ✅

证明总结

对任意3阶矩阵 A，设特征值为 λ₁, λ₂, λ₃，则：

λ₁ + λ₂ + λ₃ = tr(A) = a₁₁ + a₂₂ + a₃₃
λ₁ · λ₂ · λ₃ = det(A)

这两个性质通过特征多项式理论和韦达定理得到完美证明！
