惯性定理核心要点

不变量：正惯性指数 (p) 和负惯性指数 (q) 是二次型的固有属性，不随满秩线性变换而改变
🔢
规范形唯一性
任意二次型都可化为：
f = y12 + ... + yp2
- yp+12 - ... - yp+q2
其中：
p = 正惯性指数
q = 负惯性指数
n-p-q = 零惯性指数
🎯
判别应用
正定： p = n, q = 0
负定： p = 0, q = n
不定： p > 0, q > 0
半正定： q = 0
半负定： p = 0
几何意义：
p 和 q 决定了二次曲面的类型
核心结论：
惯性定理揭示了二次型在满秩变换下的内在不变性，正负惯性指数是二次型的本质特征，决定了二次型的分类和性质。
