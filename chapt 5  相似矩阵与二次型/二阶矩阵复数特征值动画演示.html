二阶矩阵复数特征值演示

展示实数矩阵可能具有复数特征值和特征向量

旋转矩阵示例

考虑一个90度旋转矩阵：

[
0
-1
]
[
1
0
]

这个矩阵表示平面上的90度逆时针旋转。虽然矩阵元素都是实数，但它的特征值可能是复数。

特征值计算

步骤1：构造特征方程

特征方程：det(λI - A) = 0，其中 I 是单位矩阵

det( [λ, 1; -1, λ] ) = 0

步骤2：计算行列式

计算二阶行列式：

λ × λ - (1) × (-1) = λ² + 1 = 0

步骤3：求解特征值

解方程 λ² + 1 = 0：

λ² = -1 ⇒ λ = ±√(-1) = ±i

特征值为复数：λ₁ = i，λ₂ = -i

步骤4：求解特征向量

对于 λ₁ = i，解方程 (A - iI)v = 0：

[ -i, -1; 1, -i ] [x; y] = [0; 0]

解得特征向量 v₁ = [1, i]ᵀ（复数向量）

对于 λ₂ = -i，类似地得到 v₂ = [1, -i]ᵀ

几何解释

复数特征值对应旋转变换。对于旋转矩阵，复数特征值表示旋转操作。

特征值 i 和 -i 的模为 1，表示纯旋转（没有缩放）。

重要结论

实数矩阵的特征值不一定都是实数！

二阶实数矩阵 A 的特征值可能是复数

当矩阵表示旋转或某些线性变换时，特征值可能是复数。

复数特征值通常成对出现（共轭复数），如 i 和 -i。
