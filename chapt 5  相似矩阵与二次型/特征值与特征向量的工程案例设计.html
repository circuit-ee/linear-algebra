矩阵特征值 · 工程里的“天生模式”

A·x = λ·x   真矩阵 · 真计算 · 大一能懂

Ax = λx 在说什么？

A · x = λ · x

矩阵 A 作用在向量 x 上，结果只是把 x 拉长/缩短 λ 倍，方向不变。

这种“方向不动摇”的 x 叫 特征向量，拉缩倍数 λ 叫 特征值。

工程里：系统有几种“天生姿势”x，每种按自己的速度 λ 生长或衰减。
外界激励只要是这些姿势的叠加，系统就按对应 λ 演化。

🔥 三房间热网络：温度模态

对称热导矩阵 G（隔墙热导 g₁₂、g₂₃）：

[ g₁+g₁₂   -g₁₂   0 ]
[ -g₁₂   g₂+g₁₂+g₂₃   -g₂₃ ]
[ 0   -g₂₃   g₃+g₂₃ ]

解 G·φ = λ·φ，λ 是衰减率，φ 是温度分布形状。

统一框架

电气（转移矩阵 A）能动（热导矩阵 G）

其他 λ扰动衰减速率各阶温度模态衰减率
特征向量自维持电压模式温度振型，互相 G-正交
