向量内积的动画演示

🎯 几何意义

拖动向量端点改变向量 | 点击"切换投影方向"查看双向投影
1.0
定义：
[a,b] = |a||b|cosθ
投影形式：
[a,b] = |a|( |b|cosθ ) = |b|( |a|cosθ )

几何意义：向量a与向量b的内积等于向量a的模乘以向量b在a方向上的投影，或者等于向量b的模乘以向量a在b方向上的投影。

在动画中，蓝色箭头表示向量a，红色箭头表示向量b，紫色虚线表示投影关系。

当前值：
|a| = 0
|b| = 0
θ = 0°
[a,b] = 0

🔄 对称性

观察双向投影构成的相似三角形
1.0
对称性：
[a,b] = [b,a]
几何解释：
△OAA' ∼ △OBB' ⇒ 投影比例相等

对称性：向量的内积满足交换律，即向量a与向量b的内积等于向量b与向量a的内积。

几何证明：a在b上的投影三角形与b在a上的投影三角形相似，相似比均为|a|/|b|，因此投影长度的乘积相等。

[a,b] = 0
[b,a] = 0
投影比验证：
|AA'|/|a| = 0
|BB'|/|b| = 0

📐 线性性质

左：分配律（观察a向b、c、b+c的投影） | 右：数乘性质 | 拖动滑块改变k值
1.0
分配律：
[a, b + c] = [a,b] + [a,c]
数乘性质：
[ka, b] = k[a,b] = [a, kb]

分配律：向量a与向量b加向量c的内积等于向量a与向量b的内积加上向量a与向量c的内积。几何上表现为a在b、c和b+c上的投影关系。

数乘性质：标量k与向量a的内积再与向量b做内积等于k倍的a与b的内积。几何上表现为投影长度的缩放。

1.0
分配律验证：
[a, b + c] = 0
[a,b] + [a,c] = 0
投影验证：proj(a,b+c) = 0
proj(a,b) + proj(a,c) = 0
数乘验证：
[ka, b] = 0
k[a,b] = 0

📊 施瓦茨不等式

观察cosθ ∈ [-1,1] 是核心原因
1.0
施瓦茨不等式：
|[a,b]| ≤ |a||b|
核心证明：
cosθ = [a,b]/(|a||b|) ∈ [-1,1]

施瓦茨不等式：两个向量的内积的绝对值不超过这两个向量模的乘积。

根本原因在于余弦函数的值域：因为[a,b] = |a||b|cosθ，而cosθ始终满足-1 ≤ cosθ ≤ 1，因此不等式必然成立。

动画中左侧显示cosθ在单位圆上的位置，右侧显示不等式柱状图。

|[a,b]| = 0
|a||b| = 0
cosθ = 0 ∈ [-1, 1]
