配方法化二次型为标准型

逐步操作动画演示——常规公式版（无 LaTeX）

情况一：含有平方项

特点：当二次型中含有平方项（如 x₁²）时，可直接从该变量开始配方。
准备就绪
快捷键：数字键 1
📝
理论演示
f(x₁, x₂) = x₁² + 4x₁x₂ + 3x₂²
1 配方准备：将含 x₁ 的项集中
= (x₁² + 4x₁x₂) + 3x₂²
2 完全平方：配方得到完全平方项
= (x₁ + 2x₂)² − 4x₂² + 3x₂²
3 合并同类项：化简剩余项
= (x₁ + 2x₂)² − x₂²
令：
y₁ = x₁ + 2x₂
y₂ = x₂
标准型：
f = y₁² − y₂²
6 线性变换矩阵：
[y₁] = [1 2][x₁]
[y₂] [0 1][x₂]
行列式 = 1 ≠ 0，可逆。
🎯
操作步骤详解
1识别含平方项的变量
找出含有平方项的变量（本例为 x₁²），作为配方起点。
2集中该变量的所有项
将含 x₁ 的所有项集中：x₁² + 4x₁x₂。
3配方得到完全平方
利用 (x₁ + 2x₂)² = x₁² + 4x₁x₂ + 4x₂²，需减去多余的 4x₂²。
4合并同类项化简
剩余 x₂² 项合并：3x₂² − 4x₂² = −x₂²。
5变量替换得标准型
令 y₁ = x₁ + 2x₂，y₂ = x₂，得到标准型 y₁² − y₂²。
6写出线性变换矩阵
将替换表示为矩阵，验证可逆性。
🧮
实际操作演示
f(x₁, x₂) = x₁² + 4x₁x₂ + 3x₂²
1观察含 x₁ 的项：x₁² + 4x₁x₂
2配方：(x₁ + 2x₂)² 减去多余项 −4x₂²
3合并：3x₂² − 4x₂² = −x₂²
4写出配方结果
= (x₁ + 2x₂)² − x₂²
标准型：
y₁ = x₁ + 2x₂
y₂ = x₂

f = y₁² − y₂²
5 线性变换矩阵：
C = [[1, 2], [0, 1]]，det = 1
该变换可逆，验证：f = y₁² − y₂²。

情况二：不含平方项

特点：二次型中只有混合项（如 x₁x₂），需先做变量替换制造平方项。
准备就绪
快捷键：数字键 1
📝
理论演示
f(x₁, x₂, x₃) = 2x₁x₂ + 4x₁x₃ + 6x₂x₃
1 变量替换：制造平方项
令：
x₁ = y₁ + y₂
x₂ = y₁ − y₂
x₃ = y₃
2 代入化简：得到含平方项的二次型
= 2(y₁² − y₂²) + 10y₁y₃ − 2y₂y₃
3 配方：对含 y₁ 的项配方
= 2(y₁ + 2.5y₃)² − 2y₂² − 13.5y₃²
标准型：
f = 2z₁² − 2z₂² − 13.5z₃²
5 复合线性变换矩阵：
第一步（制造平方项）：
[x₁] = [1 1 0][y₁]
[x₂] [1 −1 0][y₂]
[x₃] [0 0 1][y₃]

第二步（配方）：
[z₁] = [1 0 2.5][y₁]
[z₂] [0 1 0 ][y₂]
[z₃] [0 0 1 ][y₃]

复合矩阵 C 满足 det = −2 ≠ 0，可逆。
🎯
操作步骤详解
1识别类型：无平方项
只有混合项 2x₁x₂、4x₁x₃、6x₂x₃，没有平方项。
2变量替换制造平方项
令 x₁ = y₁ + y₂，x₂ = y₁ − y₂，则 x₁x₂ = y₁² − y₂²。
3代入并展开所有项
代入后合并得 2(y₁² − y₂²) + 10y₁y₃ − 2y₂y₃。
4对新变量配方
对 y₁ 配方：2(y₁ + 2.5y₃)² − 2y₂² − 13.5y₃²。
5继续配方剩余项
直到所有交叉项消除。
6得到最终标准型
仅含平方项：2z₁² − 2z₂² − 13.5z₃²。
7写出复合线性变换
将两次变换组合，得到从原变量到最终标准型的完整变换关系。
🧮
实际操作演示
f(x₁, x₂, x₃) = 2x₁x₂ + 4x₁x₃ + 6x₂x₃
1识别：只有混合项，没有平方项。
变量替换：制造平方项
x₁ = y₁ + y₂
x₂ = y₁ − y₂
x₃ = y₃
3代入：展开混合项
2x₁x₂ = 2(y₁² − y₂²)
4配方：对新变量配方
= 2(y₁ + 2.5y₃)² − 2y₂² − 13.5y₃²
标准型：
f = 2z₁² − 2z₂² − 13.5z₃²
5 复合变换矩阵：
C = [[1, 1, -2.5], [1, -1, 2.5], [0, 0, 1]]，det = −2 ≠ 0
该变换可逆，验证：f = 2z₁² − 2z₂² − 13.5z₃²。

方法对比总结

📊
两种情况的对比

情况一：有平方项

  • ✅ 直接配方
  • ✅ 步骤简单
  • ✅ 一步到位
  • ✅ 适用于含 xᵢ² 的二次型

情况二：无平方项

  • ⚡ 先变量替换
  • ⚡ 制造平方项
  • ⚡ 再配方
  • ⚡ 适用于只有 xᵢxⱼ 的二次型
通用步骤：
  1. 检查是否含有平方项
  2. 有平方项：直接对该变量配方
  3. 无平方项：先做变量替换 xᵢ = yᵢ + yⱼ, xⱼ = yᵢ − yⱼ
  4. 化简后得到标准型
  5. 写出可逆线性变换矩阵
⚠️ 重要提醒：必须写出可逆线性变换矩阵，这是考试与理论应用的关键步骤！
核心思想：通过配方消去交叉项，将二次型化为仅含平方项的标准型！
