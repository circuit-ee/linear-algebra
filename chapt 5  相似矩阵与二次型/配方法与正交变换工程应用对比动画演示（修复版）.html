一、二次型化简的工程意义

二次型 f(x)=xᵀAx（A为实对称矩阵）描述工程中能量、误差、稳定性等核心物理量：

  • 结构力学：应变能 U=½uᵀKu（K刚度矩阵）
  • 控制理论：Lyapunov函数 V(x)=xᵀPx（稳定性判据）
  • 信号处理：信号能量 E=xᵀRx（主成分分析）

化简目标：化为标准形（仅含平方项），提取主导因素。

二、配方法：灵活化简的实用工具

核心思想

通过可逆线性变换逐步消去交叉项，化为标准形：

f(x₁,x₂)=x₁²+2x₁x₂+3x₂² = (x₁+x₂)² + 2x₂²

工程应用

案例：RLC电路最大功率传输

负载功率 P_L=Uₛ²R_L/(Rₛ+R_L)²，配方得 P_L=Uₛ²/[ (√R_L - √Rₛ/√R_L)² + 4Rₛ ]，当R_L=Rₛ时功率最大。

动画演示：配方法求最大功率传输

步骤1：初始电路

RLC串联电路：电源电压 Uₛ = 10V，内阻 Rₛ = 50Ω，负载电阻 R_L 可变

功率公式：P_L = Uₛ²R_L/(Rₛ+R_L)²

步骤2：配方准备

将功率公式重写为：

P_L = Uₛ² / [(Rₛ+R_L)²/R_L]

令 t = (Rₛ+R_L)²/R_L，配方目标：找到使 t 最小的 R_L

步骤3：完成配方

对 t 进行配方：

t = (Rₛ+R_L)²/R_L = R_L + 2Rₛ + Rₛ²/R_L

配方得：

t = (√R_L - Rₛ/√R_L)² + 4Rₛ

步骤4：找到最优解

当 (√R_L - Rₛ/√R_L)² = 0 时，t 最小，即 R_L = Rₛ

最大功率：P_max = Uₛ²/(4Rₛ) = 100/(4×50) = 0.5W

✅ 配方法结论：负载电阻等于电源内阻时获得最大功率

特点

  • 优点：低阶便捷、快速求极值（适合2-3阶二次型）
  • 局限：结果不唯一、无明确物理意义（依赖变换路径）

三、正交变换：提取固有属性的物理工具

核心思想

利用实对称矩阵正交对角化，通过正交变换 x=Qy（QᵀQ=I）化为标准形：

f(x)=xᵀAx = yᵀ(QᵀAQ)y = λ₁y₁²+λ₂y₂²+…+λₙyₙ²

其中λᵢ为特征值（固有属性），Q为特征向量矩阵（正交模态）。

工程应用

案例：结构振动模态分析

简支梁振动方程 Kφ=ω²Mφ，正交变换得ωᵢ²（固有频率）和φᵢ（主振型），指导减振设计。

动画演示：正交变换提取模态参数

步骤1：简支梁模型

简支梁离散为3个质点，刚度矩阵 K 和质量矩阵 M 为：

K = [[2, -1, 0], [-1, 2, -1], [0, -1, 2]]

M = [[1, 0, 0], [0, 1, 0], [0, 0, 1]]

广义特征值问题：Kφ = ω²Mφ

步骤2：正交变换对角化

对刚度矩阵 K 进行正交对角化：

QᵀKQ = Λ = diag(λ₁, λ₂, λ₃)

其中 Q 由特征向量组成，Λ 为特征值对角阵

步骤3：计算特征值与特征向量

求解特征值问题得：

λ₁ = 0.5858, λ₂ = 2.0000, λ₃ = 3.4142

固有频率：ω₁ = √λ₁ = 0.765, ω₂ = √λ₂ = 1.414, ω₃ = √λ₃ = 1.848

步骤4：振动模态可视化

三个主振型（特征向量）对应不同振动模式：

1. 一阶模态：同相振动（最低频率）

2. 二阶模态：中点固定，两端反相

3. 三阶模态：交替反相（最高频率）

✅ 正交变换结论：提取了系统的固有振动特性

特点

  • 优点：结果唯一（特征值）、保留几何意义（正交模态）
  • 局限：计算复杂（需特征值分解）（依赖数值软件）

五、总结：方法选择依据

✅ 配方法：侧重代数简化，适合快速估算、低阶优化（如临时求极值）。

✅ 正交变换：侧重物理本质，适合提取系统固有特征（如模态、主成分）。

工程启示：二者互补，定性分析用配方法，定量设计用正交变换！
