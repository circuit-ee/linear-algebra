📝 向量输入

👉 核心公式：
projₑ₁ₑ₂(v₃) = proj(v₃ onto e₁) + proj(v₃ onto e₂)
e₃ = v₃ - projₑ₁ₑ₂(v₃)
准备就绪
0 初始向量
v₁ = (1.00, 0.00, 0.00)
v₂ = (1.00, 2.00, 0.00)
v₃ = (1.00, 1.00, 3.00)
1 第一步：直接取 v₁ 作为正交基
e₁ = v₁
e₁ = (1.00, 0.00, 0.00)
2 第二步：让 v₂ 与 e₁ 正交
e₂ = v₂ - proj(v₂ onto e₁)
proj(v₂ onto e₁) = (1.00, 0.00, 0.00)
e₂ = (0.00, 2.00, 0.00)
3 第三步：v₃ 减去在 e₁-e₂ 平面上的投影
projₑ₁ₑ₂(v₃) = proj(v₃ onto e₁) + proj(v₃ onto e₂)
proj(v₃ onto e₁) = (1.00, 0.00, 0.00)
proj(v₃ onto e₂) = (0.00, 1.00, 0.00)
projₑ₁ₑ₂(v₃) = (1.00, 1.00, 0.00)
（e₁-e₂平面上的总投影）
e₃ = v₃ - projₑ₁ₑ₂(v₃)
e₃ = (0.00, 0.00, 3.00)
📍 验证e₃：
e₃ = (0.00, 0.00, 3.00)
