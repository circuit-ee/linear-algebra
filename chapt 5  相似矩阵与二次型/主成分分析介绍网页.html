协方差矩阵与 PCA 主成分分析

从"两个变量怎么一起变"到"数据降维" · 大一友好 · 原生 Canvas 无依赖

★一句话串起来

方差：一个变量自己有多散（离散度）。
协方差 Cov(X,Y)：两个变量"一起怎么变"——同方向为正、反方向为负、≈0 为无线性关系。
协方差矩阵 C：多变量两两协方差排成的实对称半正定矩阵。
PCA：对 C 做正交对角化 C=QΛQᵀ，Q 的列=主成分轴（数据主轴、互相正交），Λ 的对角 λᵢ=该轴方差（信息量）。
👉 把"耦合的相关指标"解耦成"互不相关的主成分"，只留前 k 个 → 降维、去相关、保主要信息。

2协方差矩阵 C 的特征分解

C 是实对称半正定矩阵 → 可正交对角化 C = Q Λ Qᵀ。

C = Q · Λ · Qᵀ  ⇒  Q 的列 = 主成分轴（正交），Λ 的对角 λᵢ = 各轴方差（信息量）

4PCA 的真实工程应用

场景做法效果
人脸识别 Eigenface人脸展成高维向量 → PCA 取前数百主成分压缩存储 + 识别
金融风控几十个经济指标 → PCA 提 3~5 个主因子去相关、降维
传感器物联网100 路振动信号 → PCA 压到 5 路主成分实时低带宽传输
图像压缩类 JPEG/DCT 思路（正交变换去相关）保主要信息、去冗余
基因/蛋白质数据上万维表达量 → PCA 降到 2D 画图看聚类结构
📌 边界提醒：PCA 是线性方法，抓不了非线性结构（马蹄形/瑞士卷要用 t-SNE、UMAP）；量纲不同时要先 z-score 标准化。
